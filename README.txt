EDGE LEARNING - HOW TO PUT THIS ONLINE

1. Upload this whole folder (index.html + the "s" folder) to any web host:
   - a folder on edgeacademy.ae (e.g. edgeacademy.ae/learn/), or
   - Netlify Drop (app.netlify.com/drop): drag this folder in, or Vercel / GitHub Pages.
2. In Google Drive, set every class recording to "Anyone with the link - Viewer".
   Otherwise the embedded player shows "You need access".
3. Open the site and choose a class: the recording plays on the left, slides on the right.

To add or change classes, edit the list near "const L=[" in index.html
(title, Google Drive file ID, slide images).
